# Корпус: Мастер Группа Макеевой Виолетты, 3-й поток

Это архив психологической мастер-группы: еженедельные выпуски (теория и
методики проработки), транскрипции видео к ним и обсуждения участников.
Язык корпуса — русский. Отвечай на русском.

## ГЛАВНОЕ ПРАВИЛО — НОЛЬ ГАЛЛЮЦИНАЦИЙ

- Отвечай ТОЛЬКО на основании файлов этого корпуса. Не используй общие
  знания по психологии для ответов о содержании выпусков — у автора
  собственная терминология и методология, внешние знания её искажают.
- В каждом ответе указывай источник: имя файла и, по возможности, короткую
  дословную цитату, подтверждающую тезис.
- Если информации в корпусе нет — прямо скажи «в корпусе этого нет».
  Не дополняй и не домысливай.
- Не смешивай позицию автора (выпуски) с мнениями участников (комментарии).
  Всегда помечай, откуда взято: из выпуска или из обсуждения.

## Структура корпуса

- `00_Индекс.md` — ГЛАВНАЯ ТОЧКА ВХОДА. Таблица всех выпусков: номер,
  цикл, тип, описание и ссылки на файлы. Любой поиск начинай с него.
- `карта_МГ3.csv` — метаданные постов (пост; выпуск; тип; цикл; описание).
- `media/videos/transcripts/` — транскрипции видео выпусков.
  Имена вида `В06_п092_Тема.md` (В{выпуск}_п{номер поста}_{тема}).
  Файлы вида `{большое число}_*.md` — транскрипты медиа из комментариев
  (число = ID сообщения, не поста).
- `media/videos/` — видеофайлы выпусков (не читать, только упоминать).
- Файлы `*_post_{N}_comments_alltime.md` — текст поста N + все
  комментарии участников к нему. Текст поста идёт в начале файла.
  В выгрузках до сентября 2026 то же место занимает `fullchat`.
- `*_alltime.md` (один большой файл в корне, если есть) — дубликат
  текстов всех постов без комментариев. НЕ использовать: те же тексты
  есть в comments-файлах.

## Терминология корпуса (для ориентировки в поиске)

Собственные термины автора: «молочная» и «коренная» личность, БОЛЬШОЙ
АЛГОРИТМ проработки, главное противоречие среды, ЧСУ, чувство собственной
(социальной) ценности, экспресс-алгоритмы, «Бедный котик»,
«поверженный защитник», «большая попа» (БП).

Тематические циклы: Основы (В00–В04), Методика (В05–В10),
Агрессия (В11–В19), Обесценивание (В20–В27), Отвержение (В28–В29,
В40–В41), Презрение (В30–В33), Переход (В34), Сравнение (В35–В39).

## Как искать

1. Сначала открой `00_Индекс.md`, найди подходящие выпуски по описаниям
   и циклам.
2. Затем grep по транскриптам и комментариям. Учитывай морфологию
   русского: ищи по основе слова («презрени», «обесценива», «покинутост»),
   а не по полной форме.
3. Теория обычно в транскрипте выпуска; живые примеры, вопросы и разборы
   конкретных случаев — в комментариях.
4. При вопросах «как проработать X» ищи выпуски с типом «проработка»
   или «методика» в карте.

## Формат ответов

- Сначала краткий ответ, затем источники: `[В32, транскрипт]`,
  `[В20, комментарии]`.
- При пересказе методик сохраняй авторские шаги и формулировки —
  не «улучшай» и не заменяй терминами из академической психологии.
- Если вопрос затрагивает несколько выпусков цикла — перечисли все
  релевантные, а не только первый найденный.

## Чего НЕ делать

- Не редактировать и не переименовывать файлы корпуса без явной просьбы.
- Не давать психологических советов от себя — только передавать
  содержание материалов.
- Не делать выводов о конкретных участниках обсуждений.
